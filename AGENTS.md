# Instrucoes para agentes

Ao criar, revisar ou adaptar qualquer material da Ocean Health:

1. Leia integralmente `agent/AGENT-DESIGN.md`.
2. Trate `agent/brand-tokens.json` como fonte de verdade para cores e medidas.
3. Use somente os ativos em `assets/`; não recorte logos de screenshots.
4. Preserve o sistema de logo, fotografia, tipografia e corrente cursiva definido no manual.
5. Execute o checklist de `agent/design-checklist.md` antes de entregar.
6. Não invente alegacoes de cobertura, rede, preço, registro ANS, certificacoes ou disponibilidade. Quando faltarem dados, use texto de exemplo claramente identificado.
7. Entregue arquivos editaveis, exportações finais e um resumo das decisoes de design.

Se houver conflito, a ordem de prioridade e:

1. Pedido explícito do responsável pela marca.
2. Manual de marca.
3. Tokens e regras deste repositório.
4. Referencias externas.

Uma referencia externa orienta clima e composição; nunca autoriza copiar logo, layout, texto ou elementos distintivos de terceiros.
